# Развитие башен: ветки и грейды 4–7

Черновик для обсуждения. Числа стартовые, под балансировку прогонами.

## Общие правила

**Как это работает для игрока**

1. Башня покупается и качается как сейчас: грейды 1 → 2 → 3 за золото.
2. На грейде 3 в HUD появляется кнопка «Развитие». Там для **типа** башни этой расы
   видны две ветки. Выбор ветки за золото. Выбор одной ветки блокирует вторую
   для этого типа башни на весь матч.
3. После выбора ветки у всех башен этого типа открываются грейды 4 → 5 → 6 → 7.
   Каждый грейд за золото, стоимость растёт.
4. Ветка выбирается один раз на тип башни на матч. Башни, построенные позже, идут
   по той же ветке.

**Типы урона** (из эпика по броне): физический, магический, процентный.
Физическая броня режет физический, магическая режет магический, процентный
идёт от максимального здоровья и бронёй не режется.

**Единая цена грейдов** для всех башен (золото):

| Грейд | 2 | 3 | Ветка | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| Цена | 40–55 | 80–105 | 120 | 150 | 200 | 260 | 340 |

Итого полная прокачка одной башни примерно 1100–1200 золота. Это осознанно
дорого: одна башня 7-го грейда стоит как 20 башен 1-го, то есть лабиринт из
дешёвых стен остаётся выгоднее, а прокачка — это точечная ставка на ключевые
позиции (повороты и двойные проходы).

**Формат ниже**

Для каждой башни: текущие характеристики на грейде 3, две ветки, и таблица
грейдов 4–7 для каждой ветки. Урон указан за выстрел, перезарядка в мс,
дальность в клетках.

## Что потребуется от движка

Сводка новых механик, чтобы оценить объём. Отмечено, что уже есть.

| Механика | Есть | Нужно |
|---|---|---|
| Урон по времени (яд, горение) | да | горение как отдельный эффект |
| Замедление, оглушение, пробитие брони | да | пробитие по типам брони |
| Процентный урон (‰ макс. здоровья) | нет | новый тип урона |
| Выстрел по двум целям / пробитие линии | нет | новый режим одиночной атаки |
| Зона на земле (облако, лужа, споры) | нет | сущность «зона» с тиком |
| Конус | нет | геометрия атаки |
| Залп по всем в радиусе | нет | периодическая способность башни |
| Взрыв трупа | нет | хук на смерть крипа |
| Уязвимость (+% получаемого урона) | нет | новый эффект |
| Крит | нет | модификатор выстрела |
| Летающий «падает» на землю | нет | временная смена moveType |
| Корни/захват (остановка) | частично (оглушение) | можно как оглушение |
| Аура: +% урона, золото за убийство, доход | частично | расширение ауры |
| Отбрасывание назад по пути | нет | сдвиг прогресса по маршруту |
| Мортира: минимальная дальность | нет | проверка в таргетинге |

Самые дорогие по реализации: зоны на земле, конус, падение летающих,
отбрасывание. Если хочется сократить первый заход, их можно заменить на
усиление чисел, а механики добавлять по одной позже.
