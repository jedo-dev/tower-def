# Готовые промты для генерации спрайтов

Один файл — один спрайт. Внутри: шапка с контрактом листа и командой сборки, ниже — текст
промта целиком, который вставляется в UI одним куском.

## Порядок работы

1. Открыть файл нужного крипа, скопировать всё после разделительной линии.
2. В UI выбрать `google/gemini-3.1-flash-image-preview` (Nano Banana 2), «Изображения для
   обработки» оставить пустым, вставить текст, Enter.
3. Скачать результат (хранение 7 дней) и собрать лист скриптом из шапки файла:

   ```bash
   python tools/build-sprite-sheet.py raw.png src/shared/sprite/orc_grunt.png --grid 4x4 --cell 32 --normalize-rows 0,1,2
   ```

4. Прописать ключ спрайта в `src/shared/constants/sprites.ts` — как именно, написано в конце
   `docs/09-sprite-prompts.md`.

## Контракт листа крипа

`128x128` = 4 ряда по 4 кадра `32x32`:

| ряд | что в нём |
| --- | --- |
| 0 | движение вниз, на зрителя |
| 1 | движение вбок, вправо (влево игра отражает сама) |
| 2 | движение вверх, от зрителя |
| 3 | смерть |

## Если позы в ряду вышли одинаковыми

Одна генерация на весь лист — компромисс ради цены. Когда модель схлопывает позы, ряд
добивается отдельно: берётся один утверждённый кадр, кладётся в «Изображения для обработки»,
и каждый кадр просится отдельным запросом с явным описанием позы. Дороже в четыре-шестнадцать
раз, зато персонаж не плывёт.

## Башни

Промты башен пока лежат в `docs/09-sprite-prompts.md` (контракт `300x180`, 15 слотов).
Сборка та же: `--grid 5x3 --cell 60`.
